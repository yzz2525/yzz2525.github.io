    真值表中分散的一/布尔代数没法化简——>引入异或 - 奇数个 1 输出 1：(a⊕b)⊕c

    • 偶数个 1 输出 1：非(a⊕b)⊕c，也就是 XNOR 异或门![[Pasted image 20250822173034.png]] 另外，TTL 输入在低电平时需要电流 → 所以低电平更“吃力”。 高电平几乎不耗电流 → 对驱动电路几乎没有压力。假设一个门的输出为低电平：

    • 它要同时给很多个输入提供“拉低电流”。

    • 如果连的输入太多，电流超标，电平就会拉不稳 → 逻辑错误。 发现静态 1 冒险：卡诺图里相邻两格的 1 属于不同圈，且这两格对应仅一个变量变化的切换（本例 C）。

    • 消除办法：再加一个圈把这两格一起覆盖 → 在代数式里就是加一项 共识项。

    • 本例：F=ACˉ+BCF = A\bar{C} + BCF=ACˉ+BC ➜ 加 ABABAB，得到 F=ACˉ+BC+ABF = A\bar{C} + BC + AB F=ACˉ+BC+AB（功能不变但无毛刺）。 在布尔代数里有一个定理： XY+X′Z+YZ=XY+X′Z 其中 YZ 就是 共识项 (consensus term)。功能上 YZ 是冗余的，不影响真值表结果。但在实际电路里，保留它可以避免两个主项在切换时都为 0 → 防止毛刺。

    TTL 常见输出结构 —— 图腾柱输出 (Totem-pole output)。

    • 左边电路：

      • 两个三极管上下叠加（像图腾柱），上管负责拉高，下管负责拉低。

      • 输出 Vout 在两管之间切换。

    • 右边波形：

      • 当 TTL 门电路切换时，电流会在 1~2ns 内产生 尖峰 (current spike)。

      • 这是因为上下管切换过程中可能会瞬间同时导通，电源会被瞬间短路一小下 → 造成 供电干扰。

    👉 解释：这张图说明 TTL 芯片虽然逻辑是“0/1”，但物理上电路切换时会拉很大的电流，这就是为什么电路板要加 去耦电容 (0.1µF) 来稳定供电。 - TTL 芯片在 逻辑翻转瞬间，上拉管和下拉管可能 同时导通，造成电源和地之间瞬间“短路”。

    • 这会产生 电流尖峰 (spike)，持续时间只有 1~2ns。

    • 如果没有缓冲，这个尖峰电流会导致：

      • 电源电压瞬间下跌（Vcc 不稳），

      • 引起逻辑误判（本来该是高电平，却掉到阈值附近），

      • 邻近电路产生毛刺/干扰。

    🔹 去耦电容如何起作用？

    • 电容的特性：对快速电压变化，它能临时充放电，起“电压稳定器”作用。

    • 当 TTL 芯片瞬间拉电流时：

      • 电容会快速放电，补偿电流 → 防止 Vcc 瞬间掉下去。

    • 当电流尖峰过去后：

      • 电容再从电源充电，恢复能量。

    • 这样电源线就不会有大幅“抖动”，噪声被 旁路到地。

    Totem Pole 输出不允许直接并联，不然可能导致短路。 开集电极则是专门为“多路并联”设计的。 1. 单个开集电极输出

    - 晶体管的 **集电极悬空**，需要一个 **外接上拉电阻 Rext** 把电平拉到 +5V。

- 当晶体管关断 → Vout 被上拉电阻拉到高电平。

- 当晶体管导通 → Vout 被拉到地，输出低电平。  
    👉 所以输出能力主要是“拉低强、拉高弱”，上升速度取决于上拉电阻和电容（RC 延时）。

    1. 下图：多个开集电极并联

      • 不同芯片的开集电极可以直接并到一起，共用一个上拉电阻。

      • 只要有一个管子导通 → 整个输出被拉低。

      • 所以多个输出“线与”在一起，称为 有线与 (Wired-AND)。

      • 这样可以让多个器件安全地共享一条总线 (bus)，而不会像图腾柱那样打架（一个想拉高、一个想拉低 → 短路）。 反馈电路 两个反相器：双稳态电路 (bistable circuit)，能保持原有状态不变。 奇数个反相器：反馈不能稳定，会变成一个环形振荡器

    仅靠两个反相器虽然能记忆，但没有“门口”，你无法有控制地改写它。 于是把“反相器+反馈”升级成 两个门（NOR 或 NAND）交叉反馈，并给每个门一个受控输入： NOR 版（高有效）：S=1 置位(Q=1)、R=1 复位(Q=0)、S=R=0 保持；S=R=1 非法。 NAND 版（低有效）**：S̄=0 置位、R̄=0 复位、S̄=R̄=1 保持；S̄=R̄=0 非法。

    这就是 S‑R Latch（锁存器）。本质仍是“双稳态+受控入口”。 需要把该事件“记住”，就给 S 一个短脉冲；需要清掉就给 R 一个短脉冲。若SR都没有脉冲就是保持，同时有脉冲是禁用。

    D 锁存器不是把 S、R 重命名成 D、G，而是在 SR 锁存器前面加了一小段组合逻辑，把（“想写入的值 D”、“什么时候允许写入 G”）自动编码成合法的 S/R 信号，这样既能“透明跟随”，又永远不会触发 SR 的非法态。 D锁存器满足： G=1 时，Q 跟随 D； G=0 时，Q 保持不变； 任何时候都不产生 SR 的非法组合。

    触发器可以约等于两个锁存器级联 一个master 一个slave 边沿触发 D‑FF（如 74LS74）可看作“两相锁存”实现，只在时钟边沿更新；PR/CLR 是低有效且异步，能立即把输出强制为 1/0。

    • “异步有效” → 按下 PR/CLR，它立即生效，不等时钟。

    • 但释放 (从 0 → 1) 恢复时，如果恰好撞在时钟边沿，可能引发亚稳或电路不同步。

    • 所以工程上常用“双触发器同步”电路来把复位释放拉回到时钟域，这个步骤叫 reset synchronizer。按下（异步有效）：保证不论什么时候，一旦需要复位，都能马上生效，电路进入安全状态。释放（最好同步）：保证电路从“冻结状态”回到“正常工作”时，是对齐到时钟的，不会引入亚稳。

    T 触发器（T-FF） = “翻转开关”

    真值表： - T=0 → 保持原状态（Qn = Qn-1）

    • T=1 → 翻转（Qn = ~Qn-1） T-FF 常用于计数器（每次时钟来都翻转，形成分频）

    异步计数器

    • 每一级触发器都用前一级输出作为时钟，而不是共享一个全局时钟。

    • 例如：

      • Qₐ 翻转 → 驱动 Qᵦ；

      • Qᵦ 翻转 → 驱动 Q𝚌；

      • 一直“级联”到 Qd。

      • Ripple counter 多用于分频、指示灯闪烁等不怕瞬态错误的场合。

    • 如果需要可靠读数，就用 同步计数器（所有触发器共用一个时钟） 级联计数器只能得到 2ⁿ 进制，而很多实际需求（时钟、分频、FSM）需要 非 2ⁿ 的模数，所以才要专门设计模12 模12计数器

    反相器是怎么把一个“模糊的电压”变成清晰的 0 或 1 的？ 其实原理就是 电路本身的放大特性 + 正反馈 反相器能“数字化”电压，是因为晶体管在阈值区提供了强烈的增益，小偏差会被迅速推到 0 或 1。

    讲义先区分了两类 FSM：

    1. Mealy 型

      • 输出依赖于 当前状态 和 输入。

      • 因为输出直接和输入相连，所以输入一旦变化，输出可能会 异步 地立即发生变化。

      • 优点：所需状态数可能更少。

      • 缺点：可能出现毛刺 (glitch)，调试复杂。

    2. Moore 型(把 输入的不同情况，通过“扩展状态数”的方式吸收进去)

      • 输出 只依赖于状态，不直接受输入影响。

      • 输出在一个时钟周期内保持稳定，只会在下一个时钟边沿更新。

      • 优点：行为更稳定、容易设计。

      • 缺点：通常需要更多状态。

    一个 FSM 电路一般包括三个部分：

    1. 状态寄存器 (State Register)
      保存当前状态（由触发器实现）。

    2. 次态逻辑 (Next-State Logic)
      根据 当前状态 和 输入 决定下一个状态。

    3. 输出逻辑 (Output Logic)
      根据状态（以及可能的输入）产生输出。

    MTBF 就是“系统平均多久才会因为亚稳态传播而出一次错”。我们不能消灭 metastability，但通过增加同步触发器级数、放慢时钟，可以让错误出现的平均间隔时间长到远远超过系统的寿命，从工程上“等效解决”问题。

    通用随机存储器（SRAM/DRAM 都可套用）的阵列级结构 SRAM 6T（六管）存储单元 - 写：位线先设定好 → 字线开门 → 强行把值推进去。 - 读：位线先预充电 → 字线开门 → 单元轻轻拉动 → 感放放大 → 读出结果。

    独立存储器芯片（像常见的 SRAM 芯片）外面只有几类引脚： - 地址脚 (Address pins, A0…An)
    → 就像“门牌号”。告诉芯片：我要访问第几个存储单元。
    → 地址输入是单向的，由外部 CPU/FPGA 驱动。 - 数据脚 (Data pins, D0…Dm)
    → 就是数据通道。
    → 双向的： - 写操作时：外部设备把数据推到这些脚 → 存储器接收。 - 读操作时：存储器把内部的数据推出到这些脚 → 外部设备接收。 - 控制脚 (Control pins) - OE/G (Output Enable)：是否允许芯片把数据驱动到外部。 - WE/W (Write Enable)：决定这次操作是读还是写。 - CE/CS (Chip Enable/Select)：主开关，芯片是否参与总线。

    典型异步 SRAM 读时序）

    时序图里通常有这些波形： 1. 地址 (Address A[ ]) - 在某个时间点切换到新地址。 - 地址要保持稳定，才能确保芯片内部译码和感放工作。 - 保持使能，仅改地址即可滚动读取；数据总线在一个延迟后跟随地址 2. 片选信号 (E1, E2, 有的叫 CE/CS) - E1 需要拉低，E2 拉高（取决于芯片定义），表示 芯片被选中。 - 如果没被选中，数据线保持高阻（Hi-Z）。 3. 输出使能 (G / OE) - 拉低后，允许芯片把数据驱动到数据总线。 - 如果 G=1（禁止输出），即使片选有效，数据线仍然是高阻。 4. 数据总线 (Data D[ ]) - 在所有条件满足（地址稳定、芯片选中、输出使能）之后，经过一段延迟，数据才会出现在总线上。 - 这段延迟就是 访问时间 tACC (Access Time)。 - 比如数据手册写 “12ns SRAM”，意思就是 tACC ≤ 12ns。 5. 取消使能 - 当 G 拉高或 E1 拉高（取消选中），芯片会在极短时间内把数据脚放回高阻态 (Hi-Z)，释放总线。

    关键参数

    • tACC (Access Time)：从地址稳定/片选有效到数据有效的最大延迟。
    • tCE, tOE：片选有效时间、输出使能有效时间。
    • tDF (Data Float Time)：当芯片取消输出时，多久以后数据线恢复到高阻态。 ![[Pasted image 20250913174213.png]] ![[Pasted image 20250913174231.png]] 检验策略 测试数据总线
    • 方法：写入不同模式的数（比如 0000 0001、0000 0010、1111 1111、1010 1010…），再读出来比较。
    • 如果某根数据线坏了（比如 D3 永远是 0），就能检测出来。 **测试地址总线
    • 方法：在每个地址里写一个 唯一的值（比如地址号本身）。
    • 然后逐个读回，看看是不是对的。
    • 如果地址线有短路（两个地址连在一起），你写 A 地址时可能会影响 B 地址，读回就能发现问题。 实际还会用到：
    • 行行写 0，再行行写 1（检查所有单元能否稳定存 0/1）；
    • 花斑图 (checkerboard pattern, 1010 1010 / 0101 0101)（检查相邻单元是否串扰）；
    • 行走 1 / 行走 0 (walking ones/zeros)（检测单比特错误）。 反例：按“写 0→读 0→写 1→读 1→…”顺序，如果内存未焊/未使能，数据总线无人驱动但会因线电容短暂保持旧值，假象为“读对了”。 正确做法：先写满全空间，再整块读回，并在写/读之间切换地址与数据，破除线电容记忆效应；给出一个计数器驱动的最小“写 n→读 n 比较”的测试结构。

    ZBT 的目标：消除等待周期 读写不在一个时钟周期无法用时序直接同步 关键改动：写数据不在时钟沿采样，而是在时钟沿之后一点点才被采样。 这样就保证读操作的数据在某个时钟沿出来；写操作的数据在同一个时钟沿之后被采样。 于是 读和写操作可以无缝对接，不需要在它们之间插空周期。

    CPU/FPGA 对外只有一组 地址总线 + 数据总线 + 控制信号。 但系统可能有好几种器件：SRAM、ROM、外设寄存器、I/O 芯片…… 问题：怎么让同一根总线访问到不同芯片？ 答案：通过 片选信号 (Chip Enable, CE)。 内存映射 = 用 地址的高位，通过译码电路，产生不同的 CE，控制哪颗芯片被选中。

    加法器的改良 串行进位加法器延迟很大，因为必须逐级等待前一级的进位结果。 改良：定义两个信号： - Generate (G) = AB → 这一位一定会产生进位 - Propagate (P) = A ⊕ B → 这一位会传递进位 目的是加速计算进位（因为这些公式可以并行计算，不用逐级 Ripple 传播） Ci+1​=Gi​+Pi​Ci​ 下一位的进位 = 本位产生进位 + 本位传播进位 × 输入进位

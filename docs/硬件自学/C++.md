# <font color="#953734">树形结构</font>

二叉树：每个节点最多**有两个子节点**（左、右）
### 遍历二叉树：「遍历」是指按某种顺序“访问”树里所有节点。
二叉树常见的遍历顺序有三种：
前序遍历（Preorder）

- 顺序： 根 → 左 → 右
    
中序遍历（Inorder）

- 顺序： 左 → 根 → 右
    
后序遍历（Postorder）

- 顺序： 左 → 右 → 根
    
### 前序和中序可以唯一确定树

给定一棵二叉树的前序和中序遍历结果，就能唯一画出这棵树。

**为什么？**

- 前序第一个一定是根
    
- 中序里，根左边是左子树，右边是右子树
    
- 递归拆下去

怎么用来确定树？

- 前序第一个是根
    
- 中序里找到根切左右

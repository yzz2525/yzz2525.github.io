
一个时序逻辑延迟会包含时钟与触发器延迟(tCQ)，组合逻辑延迟(tPD)，setup time(tSU)延迟对吧，这个延迟加在一起决定了时序也就是时钟频率的上限
```
Tclk​≥tCQ​+tPD​+tSU
```
Tcq,cd + Tlogic,cd > Th（保持稳定的时间）
**时钟抖动（Jitter）**  
 时钟周期不稳定 ±tjitter：
- 频率上限需考虑**两倍抖动裕量**：`T ≥ Tcq + Tlogic + Tsu + 2·tjitter`；
- 保持也需加上抖动因素。工程上留裕度来抵御抖动、温漂、压摆率变化等。

<font color="#b2a2c7"><b>状态机常用器件梳理</b></font>
- 触发器 (Flip-Flop, FF)(不同类型触发器其实可以相互实现)
  - D触发器 **边沿触发**（对时钟上升沿或下降沿敏感）。 在时钟边沿到来时，把 D 的值采样 → 保存到 Q。在两个时钟边沿之间，Q 保持不变。可以加复位reset和置位set
  - JK触发器（计数器常用）![[Pasted image 20250906143441.png]]当 J=K=1 时，**JK 触发器会在每个时钟沿翻转一次**。这样，它天然就能作为一个 **T 触发器** 来用。
  - T触发器 T=0 → 保持 T=1 → 翻转  最基本的二进制计数器元件 JK触发器特别之处在于有JK两个输入变量来决定结果，更灵活 ripple的计数器用JK触发器，要是加上时序是不是就得用D触发器了
- 寄存器
  - 多个 D 触发器并排（比如 8 个 DFF → 8 位寄存器），左边有时钟输入，右边有并行数据输入/输出。 **功能**：存储多位二进制数据（1 字节、1 字、甚至更多）。

连续赋值用assign对应组合逻辑
**左边 (LHS)**

- 必须是 **网线类型 (wire, 或者 output 默认的 wire)**
    
- 表示逻辑的输出信号（相当于组合逻辑电路的“输出端”）。
    
- 不能是 `reg`（因为 reg 是在 `always` 块里赋值的）。

- 组合逻辑 always
`@(*)` = “只要右边用到的任何输入信号发生变化，就执行一次”
   - 等价于 `assign y = (a & b) | c;`
   - **左边变量必须是 `reg` 类型**，但这里的 `reg` 并不是“触发器”，而只是表示能存值。 用于实现复杂的 **组合逻辑**（if-else、case）
   - = 阻塞赋值（立即赋值，顺序执行）

 `@(posedge clk)` = 在 **时钟上升沿** 触发`@(posedge rst)` = 在 **复位信号上升沿** 触发
   - `<=` = 非阻塞赋值（适合时序逻辑）（等到周期末统一更新）  
   - 描述的是 **触发器 / 寄存器行为**。
## Verilog 中的 `reg`
- **本质**：一种 **变量数据类型**，用来在 `always` 过程块里保存值。
- 特点：
    - 可以在过程赋值 (`=` / `<=`) 中被修改；
    - **<font color="#b2a2c7"><b>可以在仿真时“保持上一次的值”，即使没有时钟</b>；</font>**
    - **并不意味着一定综合成硬件寄存器**。
## 模块基本结构

module 模块名 (端口列表)（直接在端口列表里声明类型）;    
// 端口方向声明    input  ...;    output ...;    inout  ...;（少用，双向口）    
// 内部信号定义    wire   ...;    reg    ...;    
// 电路逻辑
endmodule
- **input**
    - 输入信号，**不能在模块内部驱动**，只能作为右值使用。
    - 默认类型 = `wire`
- **output**
    - 输出信号，**必须在模块内部驱动**。
    - 默认类型 = `wire`，但如果在 `always` 块里赋值，必须声明为 `reg`。
## Verilog 默认规则
- **input**：默认是 **wire** 类型。
- **output**：默认也是 **wire** 类型。
- **inout**：默认是 **wire** 类型。
如果要在时序逻辑里面赋值，那要另外声明reg out`

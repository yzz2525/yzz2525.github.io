## **IDE**

全称是 **Integrated Development Environment**  
中文叫：**集成开发环境**。

一句话定义：

> **IDE 就是专门为写代码设计的"全功能工作台"。**

### IDE 的核心功能

一个 IDE 通常包含以下核心功能：

| 功能                      | 举例说明                             |
| ------------------------- | ------------------------------------ |
| 📝 **代码编辑器**         | 能识别语法高亮、自动补全、智能提示   |
| 🧠 **调试器（Debugger）** | 可以单步执行、打断点、查看变量       |
| ⚙️ **运行/构建工具**      | 一键运行、编译、构建项目             |
| 📦 **包与环境管理**       | 管理依赖库（比如 Conda、pip）        |
| 🧪 **终端 / 控制台**      | 内置命令行，不用单独开 CMD           |
| 📄 **项目浏览器**         | 左侧树状结构管理代码文件夹           |
| 🎨 **可视化工具**         | 有时还带图形界面设计器、绘图预览器等 |
